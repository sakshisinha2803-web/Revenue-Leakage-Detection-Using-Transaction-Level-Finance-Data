# Revenue-Leakage-Detection-Using-Transaction-Level-Finance-Data



## Business Objective
Enable finance and revenue assurance teams to detect, quantify, and reduce revenue leakage by analyzing transaction-level data and identifying high-risk customers, products, and regions.

## Tools Used
- SQL
- Python (Pandas, NumPy)
- Power BI
- Excel

## Project Structure
- `data/` – raw and processed transaction datasets
- `sql/` – analytical queries and KPI calculations
- `notebooks/` – data cleaning, exploratory analysis, and feature engineering
- `dashboard/` – Power BI dashboard and preview screenshots
